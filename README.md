# 과외학습자료

과외 수업용 학습자료 모음입니다. A4 인쇄에 맞춘 self-contained HTML 문제풀이·개념정리 자료를 과목별로 정리합니다.

## 디렉토리 구조

```
과외학습자료/
├── 과외-수학/
│   └── 확률과통계/                                 # 개념정리 · 중단원/대단원 마무리 · 발전문제 · 공식 빈칸테스트
└── 과외-영어/
    ├── 단어/                                       # EBS 수능특강 유형 13~20 지문별 단어 정리
    ├── 분석노트/                                   # 지문 원문 · 구문 · 해석 · 논리 구조
    ├── 변형문제/                                   # 지문별 변형 문항 + 영작 서술형
    ├── 일치추론/                                   # 고난도 내용일치 문항
    └── 9월모평/                                    # 9월 모평 대비 단어·숙어 정리 + 출제 스타일 분석
```

## 사용법

각 `.html` 파일은 외부 의존성 없이 그 자체로 완결되어 있습니다.

- **보기**: HTML 파일을 웹 브라우저로 엽니다.
- **인쇄/PDF**: 브라우저 인쇄(⌘P / Ctrl+P)에서 A4 용지로 저장하면 인쇄용 PDF가 만들어집니다.

## 라이선스

개인 과외/학습 용도의 자료입니다.
