II. 확률 — 개념 정리p. 1

중단원 1. 확률의 뜻과 활용

1-1. 시행·표본공간·사건

  • 시행: 같은 조건에서 반복할 수 있고, 그 결과가 우연에 의해 결정되는 관찰이나 실험
  • 표본공간 S: 한 시행에서 일어날 수 있는 모든 결과의 집합
  • 사건: 표본공간의 부분집합. 예) 주사위에서 짝수가 나오는 사건 A = {2, 4, 6}
  • 근원사건: 더 이상 쪼갤 수 없는 한 가지 결과 (원소가 1개인 사건)
사건의 연산 — 집합과 똑같이 생각
용어기호의미
합사건A ∪ BA 또는 B 중 적어도 하나가 일어나는 사건
곱사건A ∩ BA 와 B 가 동시에 일어나는 사건
배반사건A ∩ B = ∅A 와 B 가 동시에 일어날 수 없는 관계
여사건AcA 가 일어나지 않는 사건

1-2. 수학적 확률

표본공간 S 의 각 근원사건이 같은 정도로 기대될 때(동등한 가능성), 사건 A 의 확률은 다음과 같다.

P(A) = n(A)n(S) = (사건 A 의 원소 수)(표본공간의 원소 수)
확률의 기본 성질
①   0 ≤ P(A) ≤ 1
②   P(S) = 1   (반드시 일어나는 사건)
③   P(∅) = 0   (절대 일어나지 않는 사건)
예제 — 조합으로 세기

빨강 공 3개, 파랑 공 4개가 든 주머니에서 2개를 동시에 꺼낼 때, 둘 다 빨강일 확률을 구하라.

"동시에 꺼낸다" = 순서 없음 → 조합

분모: 7C2 = 7 × 62 = 21,   분자: 3C2 = 3
P = 321 = 17
II. 확률 — 개념 정리p. 2

1-3. 확률의 덧셈정리

두 사건 A, B 가 동시에 일어날 수 있을 때 (배반이 아닐 때),

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

두 사건이 배반이면 P(A ∩ B) = 0 이므로,

P(A ∪ B) = P(A) + P(B)
예제 — 덧셈정리

1부터 10까지 적힌 공에서 1개를 뽑을 때, 2의 배수 또는 3의 배수일 확률을 구하라.

A = {2,4,6,8,10} → 5개,   B = {3,6,9} → 3개,   A∩B = {6} → 1개

P(A∪B) = 510 + 310 − 110 = 710
주의 "배반이 아닌데 겹치는 부분을 안 빼고" P(A)+P(B) 로 쓰는 실수가 가장 흔합니다. 배반인지 반드시 확인하세요.

1-4. 여사건의 확률

P(Ac) = 1 − P(A)

"적어도", "~이상", "~아닌" 이란 표현이 보이면 여사건을 먼저 떠올리세요. 직접 세면 경우가 많지만, 반대쪽(여사건)은 경우가 적어 훨씬 쉽습니다.

예제 — 여사건 활용

동전 3개를 던질 때, 적어도 1번 앞면이 나올 확률을 구하라.

"적어도 1번 앞면" 의 여사건 = "모두 뒷면"

P(모두 뒷면) = (12)3 = 18
P(적어도 1번 앞면) = 1 − 18 = 78
신호 단어 → 도구 매칭
신호 단어도구
동시에 꺼낸다조합 nCr
또는 (∪)덧셈정리
적어도 / 이상여사건 1 − P(Ac)
II. 확률 — 개념 정리p. 3

1-5. 통계적 확률

수학적 확률은 "동등한 가능성"을 전제로 하므로, 모든 상황에 쓸 수는 없습니다. 예를 들어 "내일 비가 올 확률" 같은 것은 동전처럼 경우를 셀 수 없습니다.

같은 시행을 n 번 반복할 때 사건 A 가 r 번 일어났다면,

통계적 확률 = rn   (상대도수)

n 이 충분히 크면 상대도수는 일정한 값에 가까워지는데, 이 값을 통계적 확률이라 합니다.

수학적 확률 vs 통계적 확률
구분수학적 확률통계적 확률
방법경우의 수를 세어 계산반복 실험의 상대도수
전제동등한 가능성충분히 많은 시행
관계시행 횟수 n → ∞ 이면 통계적 확률은 수학적 확률에 수렴
예제 — 통계적 확률

자유투를 200번 던져 150번 성공했다면, 이 선수의 성공 확률은 약 얼마로 볼 수 있는가?

P ≈ 150200 = 0.75
포인트 시험에서 통계적 확률 자체를 묻는 문제는 많지 않지만, "상대도수의 극한이 수학적 확률과 같다"는 관계를 서술형으로 묻는 경우가 있습니다.

중단원 2. 조건부확률

2-1. 조건부확률의 뜻

사건 A 가 일어났다는 조건 아래에서 사건 B 가 일어날 확률을 조건부확률이라 하며, P(B|A) 로 쓴다.

P(B|A) = P(A ∩ B)P(A)   (P(A) > 0)

핵심은 분모가 전체(S)에서 사건 A로 바뀐다는 것이다. "~중에서", "~일 때" 라는 표현이 나오면 조건부확률을 의심하라.

표 문제는 2×2 표로 정리

분류가 두 가지(예: 남/여, 합격/불합격)인 문제는 아래처럼 2×2 표를 먼저 만들면 조건부확률의 분모·분자를 바로 읽을 수 있다.

사건 B사건 Bc합계
사건 Aaba+b
사건 Accdc+d
합계a+cb+dn
예제 — 조건부확률

어느 학교에서 안경을 쓴 학생이 40명, 그중 남학생이 25명이다. 안경을 쓴 학생 중에서 임의로 1명을 뽑을 때 남학생일 확률을 구하라.

"안경을 쓴 학생 중에서" → 조건부확률, 분모 = 40

P(남학생|안경) = 2540 = 58
함정 조건부확률에서 분모를 전체 학생 수로 잡는 실수가 매우 많습니다. "~중에서"라는 조건이 붙으면 분모는 반드시 조건에 해당하는 수입니다.

2-2. 확률의 곱셈정리 (비복원 문제의 핵심)

조건부확률 공식을 변형하면 두 사건이 동시에 일어나는 확률을 구할 수 있다.

P(A ∩ B) = P(A) × P(B|A)

이 공식이 특히 빛을 발하는 곳은 비복원추출(뽑은 것을 되돌려 넣지 않는 경우)이다. 두 번째 뽑을 때 전체 개수가 1 줄어들기 때문에, 두 번째 확률은 조건부확률이 된다.

예제 — 비복원 곱셈정리

주머니에 빨간 공 3개, 파란 공 4개가 들어 있다. 공을 하나씩 두 번 꺼낼 때(비복원), 두 개 모두 빨간 공일 확률을 구하라.

첫 번째: 빨강 확률 = 37

두 번째: 빨강 하나 빠졌으므로 = 26

P(둘 다 빨강) = 37 × 26 = 642 = 17
TIP 비복원에서는 두 번째 분모가 반드시 1 줄어든다. 복원이면 분모가 그대로이므로 단순 곱셈이 된다.
II. 확률 — 개념 정리p. 6

2-3. 독립과 종속

두 사건 A, B 가 서로 영향을 주지 않으면 독립, 영향을 주면 종속이라 한다.

독립의 세 가지 동치 조건 — 어느 것이든 하나만 확인
①   P(A ∩ B) = P(A) · P(B)
②   P(B|A) = P(B)   (A가 일어나든 말든 B 확률 불변)
③   P(A|B) = P(A)

위 세 조건 중 어느 하나가 성립하면 나머지도 모두 성립한다.

종속: 위 조건이 성립하지 않으면 두 사건은 종속이다.

예제 — 독립 판정

P(A) = 12, P(B) = 13, P(A ∩ B) = 16 일 때 A 와 B 는 독립인가?

P(A) × P(B) = 12 × 13 = 16 = P(A ∩ B)   ⟹   독립
함정 — 독립 ≠ 배반
  • 배반: A ∩ B = ∅ → 둘이 동시에 일어나지 않는다
  • 독립: P(A ∩ B) = P(A)P(B) → 한쪽이 다른 쪽에 영향을 주지 않는다
  • 두 사건이 배반이면서 동시에 독립인 경우는 P(A)=0 또는 P(B)=0 일 때뿐이다.
II. 확률 — 개념 정리p. 7

2-4. 독립시행의 확률

같은 시행을 독립적으로 n 번 반복할 때, 어떤 사건이 정확히 r 번 일어날 확률이다. (한 번의 성공 확률 p, 실패 확률 1−p)

nCr · pr · (1−p)n−r
공식의 의미 — 세 부분으로 나누어 보기
  • nCr : n 번 중 어디서 r 번 성공할지 자리 선택
  • pr : 성공 r 번의 확률
  • (1−p)n−r : 실패 (n−r) 번의 확률
예제 — 독립시행

주사위를 4번 던질 때, 6의 눈이 정확히 2번 나올 확률을 구하라.

n = 4, r = 2, p = 16, 1−p = 56

4C2 · (16)2 · (56)2 = 6 × 136 × 2536 = 1501296 = 25216
"적어도 1번" 이면 여사건 활용
P(적어도 1번) = 1 − (1−p)n

모두 실패할 확률을 빼는 것이 훨씬 빠르다.

II. 확률 — 개념 정리p. 9

공부 순서 제안

  1. 표본공간·사건을 집합으로 나타내는 연습 — 합사건(∪), 곱사건(∩), 여사건을 정확히 쓰기
  2. 수학적 확률: 경우의 수를 세는 도구(순열·조합)를 먼저 복습한 뒤, P(A) = n(A)n(S) 에 넣는 연습
  3. 덧셈정리: 배반인지 아닌지 구분 → 배반이면 그냥 더하고, 아니면 겹치는 부분 빼기
  4. 여사건: "적어도", "이상" 이 보이면 자동으로 1 − (반대) 를 쓰는 습관 기르기
  5. 조건부확률: "~중에서" → 분모 바꾸기, 표 문제는 2×2 표로 정리
  6. 곱셈정리: 비복원 문제는 두 번째 분모가 줄어드는 것을 확인
  7. 독립시행: nCr × pr × (1−p)n−r 공식 외우고, "적어도"는 여사건으로

자주 틀리는 부분 — 시험 직전 체크

아래 5가지만 안 틀려도 점수가 오릅니다
  1. "동시에 꺼냄"인데 순열(P)로 세는 실수 — 순서 없이 꺼내는 것이므로 조합(C)을 써야 한다.
  2. 배반이 아닌데 P(A∪B) = P(A)+P(B) 로 쓰는 실수 — 배반이 아니면 P(A∩B) 를 빼야 한다.
  3. 조건부확률에서 분모를 전체로 잡는 실수 — "~중에서"가 있으면 분모는 조건에 해당하는 수이다.
  4. 독립과 배반을 혼동하는 실수 — 배반은 "동시에 안 일어남", 독립은 "영향 없음". 완전히 다른 개념이다.
  5. 독립시행에서 nCr 을 빠뜨리는 실수 — 자리 선택 조합 없이 pr(1−p)n−r 만 쓰면 틀린다.
마무리 확률 단원은 "경우를 세고 → 공식에 넣고 → 더하거나 빼는" 흐름이 80 %입니다. 문제를 읽고 어떤 도구(조합, 덧셈정리, 여사건, 조건부확률, 독립시행)를 쓸지 판단하는 연습이 가장 중요합니다.
