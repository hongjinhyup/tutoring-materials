발전 11확률분포 · 정규분포

정규분포 실생활 — 단위 통일에 주의

문제: 어느 집단의 한 달 통화량 X가 정규분포 N(150, 152)(분)을 따른다. 임의로 뽑은 1명이 2시간 이상 통화할 확률을 구하시오. (단, P(0 ≤ Z ≤ 2) = 0.4772)

개념 먼저 정규분포 X ~ N(m, σ2)는 Z = X − mσ 로 표준화한다. 여기서 m = 150, σ = 15이다. 또한 대칭성에 의해 P(Z ≥ −2) = 0.5 + P(0 ≤ Z ≤ 2)이다.
풀이 흐름: 단위 통일(2시간 → 120분) → 표준화 → 표준정규분포표
[1단계] 단위를 분으로 통일한다

분포의 단위가 분이므로, 문제의 "2시간"을 분으로 바꾸어야 한다.

2시간 = 2 × 60 = 120 (분)
함정 "2시간"을 그대로 2로 쓰면 안 된다. 분포가 분 단위이므로 반드시 120분으로 통일한 뒤 표준화한다.
[2단계] X = 120을 표준화한다

구하는 것은 P(X ≥ 120)이다. 경계값 120을 표준화한다.

Z = 120 − 15015 = −3015 = −2
[3단계] 표준정규분포표를 이용해 확률을 구한다

표준화하면 P(X ≥ 120) = P(Z ≥ −2)이다. Z = −2의 오른쪽 넓이는 0보다 작은 부분(0.5)과 0~2 부분을 더한 것이다.

P(Z ≥ −2) = 0.5 + P(0 ≤ Z ≤ 2) = 0.5 + 0.4772 = 0.9772

0.9772

발전 12확률분포 · 이항분포의 정규근사

이항분포를 정규분포로 근사하기

문제: 확률변수 X가 이항분포 B(n, 16)을 따르고 E(X) = 30일 때, P(n12 ≤ X ≤ n6) 을 구하시오. (단, P(0 ≤ Z ≤ 3) = 0.4987)

개념 먼저 X ~ B(n, p)이면 E(X) = np, V(X) = npq (q = 1 − p)이다. n이 충분히 크면 B(n, p) ≈ N(np, npq)로 근사하여 표준화한다.
풀이 흐름: E = np 로 n 결정 → m·σ 계산 → 정규근사 → 표준화
[1단계] E(X) = np 를 이용해 n을 구한다

평균이 30이고 성공 확률이 16이므로

n × 16 = 30  ⇒  n = 30 × 6 = 180
[2단계] 평균 m과 표준편차 σ를 구한다

분산은 npq이다. p = 16, q = 56이므로

m = 30,   V(X) = 180 × 16 × 56 = 25
σ = 25 = 5
[3단계] 구간의 양 끝을 숫자로 바꾼다

n = 180을 대입하면 구간 경계가 정해진다.

n12 = 18012 = 15,   n6 = 1806 = 30

즉 구하는 확률은 P(15 ≤ X ≤ 30)이다.

[4단계] 정규근사 후 표준화하여 확률을 구한다

X ≈ N(30, 52)로 보고 두 경계 15, 30을 각각 표준화한다.

15 → 15 − 305 = −3,   30 → 30 − 305 = 0
P(15 ≤ X ≤ 30) = P(−3 ≤ Z ≤ 0) = P(0 ≤ Z ≤ 3) = 0.4987

(대칭성: P(−3 ≤ Z ≤ 0) = P(0 ≤ Z ≤ 3))

0.4987

발전 13확률분포 · 연속확률변수

대칭인 확률밀도함수

문제: 0 ≤ X ≤ 4에서 정의된 연속확률변수 X의 확률밀도함수 f(x)가 모든 x에 대하여 f(2 − x) = f(2 + x)를 만족한다. P(0 ≤ X ≤ 1) = 16일 때 P(2 ≤ X ≤ 3)을 구하시오.

개념 먼저 확률밀도함수에서 전체 넓이는 1이고, 구간의 넓이가 곧 확률이다. f(a − x) = f(a + x)이면 그래프는 x = a에 대하여 좌우 대칭이므로, a를 기준으로 대칭인 두 구간의 확률은 같다.
풀이 흐름: 대칭축 x=2 찾기 → 대칭 구간 확률 같음 → 전체 1에서 빼기 → 절반
[1단계] 대칭축을 찾는다

조건 f(2 − x) = f(2 + x)는 x = 2에서 같은 거리만큼 떨어진 두 점의 함숫값이 같다는 뜻이다. 따라서 그래프는 x = 2에 대하여 대칭이다.

[2단계] 대칭을 이용해 양 끝 구간의 확률을 옮긴다

구간 [0, 1]을 x = 2에 대하여 접으면 [3, 4]가 된다. 대칭이므로 두 구간의 넓이(확률)는 같다.

P(0 ≤ X ≤ 1) = P(3 ≤ X ≤ 4) = 16
[3단계] 전체 넓이 1에서 양 끝을 빼 가운데 구간을 구한다

전체 [0, 4]의 확률은 1이다. 여기서 양 끝 [0,1]과 [3,4]를 빼면 가운데 [1, 3]이 남는다.

P(1 ≤ X ≤ 3) = 1 − 16 − 16 = 1 − 26 = 23
[4단계] 가운데 구간도 대칭이므로 절반을 취한다

구간 [1, 3]은 대칭축 x = 2를 중심으로 [1,2]와 [2,3]으로 나뉘고, 둘은 서로 대칭이므로 넓이가 같다. 따라서 [2, 3]은 [1, 3]의 절반이다.

P(2 ≤ X ≤ 3) = 12 × 23 = 13

13

발전 14확률분포 · 독립 시행의 합

주사위로 움직이는 바둑돌의 평균과 표준편차

문제: 수직선의 원점에 바둑돌이 있다. 주사위를 한 번 던져 짝수가 나오면 +2, 홀수가 나오면 −1만큼 바둑돌을 이동시킨다. 주사위를 3번 던진 후 바둑돌의 위치를 X라 할 때, X의 평균과 표준편차를 구하시오.

개념 먼저 한 번 던질 때의 이동량을 T라 하면 X = T1 + T2 + T3이다. 독립인 확률변수의 합에서는 E(X) = 3E(T), V(X) = 3V(T)가 성립한다. (분산은 평균처럼 그대로 더해지지만, 표준편차는 더해지지 않고 V를 구한 뒤 √를 씌운다.)
풀이 흐름: 1회 T의 분포표 → E(T), V(T) → ×3 → σ(X)=√V(X)
[1단계] 한 번 던질 때 이동량 T의 분포표를 만든다

주사위에서 짝수(2,4,6)와 홀수(1,3,5)가 나올 확률은 각각 36 = 12이다.

T+2 (짝수)−1 (홀수)합
P 12 12 1
[2단계] 1회 이동량의 평균 E(T)를 구한다

E(T) = Σ(값 × 확률)로 계산한다.

E(T) = 2 × 12 + (−1) × 12 = 1 − 12 = 12
[3단계] 1회 이동량의 분산 V(T)를 구한다

먼저 E(T2)를 구한 뒤 V(T) = E(T2) − {E(T)}2를 적용한다.

E(T2) = 22 × 12 + (−1)2 × 12 = 4 × 12 + 1 × 12 = 52
V(T) = 52 − (12)2 = 52 − 14 = 104 − 14 = 94
[4단계] 3번 던지므로 ×3 하여 X의 평균·분산을 구한다

독립합이므로 평균과 분산을 각각 3배 한다.

E(X) = 3 × 12 = 32
V(X) = 3 × 94 = 274
[5단계] 표준편차는 분산에 √를 씌운다
σ(X) = 274 = 274 = 332

(27 = 9 × 3 = 33)

E(X) = 32,   σ(X) = 332

발전 15확률분포 · 정규분포 → 이항분포 정규근사

정규분포로 p를 구한 뒤 이항분포를 정규근사하는 2단 문제

문제: 어느 학교 학생의 심박수 X가 정규분포 N(80, 102)을 따른다. 심박수가 60 이하이면 서맥, 100 이상이면 빈맥이라 한다. 이 학교 학생 600명 중 서맥 또는 빈맥인 학생 수가 12명 미만일 확률을 구하시오.
(단, P(0 ≤ Z ≤ 2) = 0.48, P(0 ≤ Z ≤ 2.5) = 0.49)

개념 먼저 두 단계로 나뉘는 문제이다. 1단계에서는 정규분포로 "한 학생이 서맥/빈맥일 확률 p"를 구하고, 2단계에서는 학생 수가 B(600, p)를 따르므로 이를 N(600p, 600pq)로 정규근사한다.
풀이 흐름: ① 정규분포로 한 명의 확률 p → ② B(600, p)를 정규근사 → 표준화
[1단계] 한 학생이 서맥 또는 빈맥일 확률 p를 구한다

먼저 서맥(X ≤ 60)의 확률이다. 경계 60을 m = 80, σ = 10으로 표준화한다.

P(X ≤ 60) = P(Z ≤ 60 − 8010) = P(Z ≤ −2) = 0.5 − 0.48 = 0.02

다음으로 빈맥(X ≥ 100)의 확률이다. 경계 100을 표준화한다.

P(X ≥ 100) = P(Z ≥ 100 − 8010) = P(Z ≥ 2) = 0.5 − 0.48 = 0.02

두 사건은 동시에 일어날 수 없으므로 확률을 더한다.

p = 0.02 + 0.02 = 0.04
[2단계] 학생 수 Y ~ B(600, 0.04)의 평균과 표준편차를 구한다

서맥/빈맥 학생 수를 Y라 하면 Y ~ B(600, 0.04)이다. (q = 1 − 0.04 = 0.96)

E(Y) = 600 × 0.04 = 24
V(Y) = 600 × 0.04 × 0.96 = 23.04,   σ(Y) = 23.04 = 4.8
[3단계] 정규근사 후 표준화하여 확률을 구한다

Y ≈ N(24, 4.82)로 보고 경계 12를 표준화한다.

P(Y < 12) = P(Z < 12 − 244.8) = P(Z < −2.5)

대칭성에 의해 P(Z < −2.5) = P(Z > 2.5)이다.

P(Z < −2.5) = 0.5 − P(0 ≤ Z ≤ 2.5) = 0.5 − 0.49 = 0.01

0.01

함정 12 − 244.8 = −124.8 = −2.5이다. 나눗셈을 −2.4 등으로 잘못 계산하지 않도록 주의한다. (12 ÷ 4.8 = 2.5)

발전 12 ~ 14 · 통계적추정 (III-2)

발전 12통계적추정 · 표본평균

주머니에서 복원추출한 표본평균

문제: 1이 적힌 공 1개와 3이 적힌 공 n개가 들어 있는 주머니에서 복원추출로 2번 꺼내어 나온 수의 평균을 X라 하자. P(X = 2) = 38일 때 n의 값을 구하시오.

개념 먼저 두 번 꺼낸 수를 a, b라 하면 평균은 X = a + b2이다. 평균이 2가 되려면 a + b = 4, 즉 (1, 3) 또는 (3, 1)이어야 한다. 복원추출이므로 매번 1을 뽑을 확률은 1n + 1, 3을 뽑을 확률은 nn + 1이다. (공은 총 n + 1개)
풀이 흐름: X̄=2 되는 경우 → 확률식 세우기 → 이차방정식 풀이
[1단계] X̄ = 2가 되는 경우를 찾는다

평균이 2이려면 두 수의 합이 4여야 한다. 공에 적힌 수는 1과 3뿐이므로 (첫 번째, 두 번째) = (1, 3) 또는 (3, 1) 두 가지이다.

[2단계] 각 경우의 확률을 곱하고 더해 확률식을 세운다

(1, 3)일 확률은 1n + 1 × nn + 1이고, (3, 1)일 확률도 같다. 두 경우를 더하므로 2배 한다.

P(X = 2) = 2 × 1n + 1 × nn + 1 = 2n(n + 1)2
[3단계] 주어진 값 3/8과 같다고 놓고 정리한다
2n(n + 1)2 = 38

양변을 교차로 곱한다 (8 × 2n = 3 × (n+1)2).

16n = 3(n + 1)2 = 3(n2 + 2n + 1) = 3n2 + 6n + 3
[4단계] 이차방정식을 풀어 n을 구한다

모든 항을 한쪽으로 모은다.

3n2 + 6n + 3 − 16n = 0  ⇒  3n2 − 10n + 3 = 0

인수분해한다.

(3n − 1)(n − 3) = 0  ⇒  n = 13  또는  n = 3

n은 공의 개수이므로 자연수여야 한다. n = 13은 부적합하므로 버린다.

n = 3

발전 13통계적추정 · 표본평균의 분포

P(X < 110) = P(X̄ ≥ a)를 만족하는 a

문제: 모집단의 확률변수 X가 정규분포 N(100, 52)을 따른다. 이 모집단에서 크기 4인 표본을 뽑아 표본평균을 X라 할 때, P(X < 110) = P(X ≥ a) 를 만족시키는 a의 값을 구하시오.

개념 먼저 모집단이 N(m, σ2)이고 표본의 크기가 n이면, 표본평균은 X ~ N(m, (σn)2)을 따른다. 즉 표본평균의 표준편차는 σn로 줄어든다. 또 대칭성에 의해 P(Z < 2) = P(Z ≥ −2)이다.
풀이 흐름: 좌변·우변 각각 표준화 → Z값 대칭으로 연결 → a 계산
[1단계] 좌변 P(X < 110)을 표준화한다

X ~ N(100, 52)이므로 m = 100, σ = 5로 표준화한다.

P(X < 110) = P(Z < 110 − 1005) = P(Z < 2)
[2단계] 표본평균 X̄의 표준편차를 구한다

표본의 크기가 n = 4이므로

σ(X) = σn = 54 = 52 = 2.5

즉 X ~ N(100, 2.52)이다.

[3단계] 우변 P(X̄ ≥ a)를 표준화한다
P(X ≥ a) = P(Z ≥ a − 1002.5)
[4단계] 좌변과 우변을 대칭으로 연결해 a를 구한다

좌변은 P(Z < 2)이다. 대칭성에 의해 이는 P(Z ≥ −2)와 같다. 우변과 비교하면 표준화한 값이 −2이어야 한다.

a − 1002.5 = −2  ⇒  a − 100 = −5  ⇒  a = 95
포인트 좌변은 부등호가 <(작다)이고 우변은 ≥(크거나 같다)이다. 방향이 반대이므로 P(Z < 2) = P(Z ≥ −2)처럼 부호를 바꾼 대칭값으로 연결해야 한다.

a = 95

발전 14통계적추정 · 신뢰구간의 길이

신뢰구간의 길이를 절반으로 만드는 표본 크기

문제: 정규분포를 따르는 모집단에서 크기 50인 표본으로 모평균 m의 95% 신뢰구간 a ≤ m ≤ b를 얻었다. 같은 신뢰도로 크기 n인 표본을 사용했더니 신뢰구간이 c ≤ m ≤ d이고 d − c = 12(b − a)였다. n의 값을 구하시오.

개념 먼저 95% 신뢰구간의 길이는 2 × 1.96 × σn이다. 여기서 신뢰도(1.96)와 모표준편차 σ는 그대로이므로, 길이는 1n에만 비례한다. 즉 표본 크기가 커질수록 신뢰구간은 좁아진다.
풀이 흐름: 두 구간의 길이식 → 비(½) 식 세우기 → √n 정리 → n
[1단계] 두 신뢰구간의 길이를 식으로 쓴다

크기 50일 때의 길이 b − a와 크기 n일 때의 길이 d − c를 각각 쓴다.

b − a = 2 × 1.96 × σ50
d − c = 2 × 1.96 × σn
[2단계] "길이가 절반" 조건을 식으로 옮긴다

d − c = 12(b − a)에 두 길이식을 대입한다. 공통인 2 × 1.96 × σ는 양변에서 약분된다.

n = (250)2 = 4 × 50 = 200
