표준편차 σ(X) = V(X)

III. 통계 — 대단원 마무리 풀이p. 1

문항별 필수 개념 안내

각 문항을 풀기 위해 반드시 알아야 하는 개념을 정리하였다. 개념을 먼저 확인한 뒤 풀이에 들어간다.

❶ 이산확률변수  → 종합 1

확률변수가 취하는 값을 셀 수 있으면 이산, 연속적인 측정값이면 연속확률변수이다. "개수", "횟수"는 이산, "시간", "길이", "무게"는 연속이다.

❷ 이산확률분포와 기댓값·분산  → 종합 2, 3, 4, 5

확률변수 X가 취하는 각 값에 대하여 확률을 대응시킨 표를 확률분포표라 한다. 모든 확률의 합은 1이다.

E(X) = Σxipi로 평균을, V(X) = E(X2) − {E(X)}2로 분산을 구한다. 일차변환 Y = aX + b이면 V(Y) = a2V(X)이다.

❸ 이항분포  → 종합 6, 7

성공 확률 p인 독립 시행을 n회 반복할 때, 성공 횟수 X는 이항분포 B(n, p)를 따른다. E(X) = np,   V(X) = npq  (q = 1 − p)이다.

점화관계 P(X=n)과 P(X=n−1)의 비를 이용하여 p를 역산할 수 있다.

❹ 정규분포와 표준화  → 종합 8, 9, 10

X ~ N(m, σ2)일 때 Z = X − mσ 로 표준화하면 Z ~ N(0, 1)이다. 구간 중점이 평균과 일치할 때 확률이 최대이다.

❺ 표본평균의 분포  → 종합 11, 12

모집단 N(m, σ2)에서 크기 n인 표본을 추출하면 X ~ N(m, σ2n)이다. n이 클수록 분산은 줄어든다.

❻ 정규근사와 실생활 응용  → 종합 13

표본평균으로 변환 후 불량 확률을 구하고, 이항분포의 평균(np)으로 전체 불량 수를 추정한다.

❼ 모평균의 신뢰구간 추정  → 종합 14, 서술형 18

신뢰도 95% 신뢰구간: X ± 1.96 × σn,  99%: X ± 2.58 × σn이다. 신뢰구간의 길이 b − a로 최소 표본 크기를 구할 수 있다.

❽ 서술형 풀이 전략  → 서술형 15, 16, 17

비복원 추출의 대칭성, 상위 비율에서 Z값 역산, 모분산 계산 후 표본평균의 표준편차를 구하는 절차를 단계별로 서술한다.

문제: 다음 중 이산확률변수인 것은?
① A 반 학생들의 충치의 개수  ② B 공장에서 생산한 전구의 수명
③ C 정류장에서 버스를 기다리는 시간  ④ D 목장에서 하루 동안 생산된 우유의 양
⑤ E 지역 주민들이 소유한 자동차의 주행 거리

풀이 패턴: 셀 수 있으면 이산, 연속적이면 연속
  • ① 충치의 개수: 0, 1, 2, … → 셀 수 있음 → 이산확률변수
  • ② 전구의 수명: 연속적인 시간 → 연속확률변수
  • ③ 버스 기다리는 시간: 연속 → 연속확률변수
  • ④ 우유의 양: 연속 → 연속확률변수
  • ⑤ 주행 거리: 연속 → 연속확률변수

종합 7

이항분포 점화관계

문제: X ~ B(n, p), V(X) = 1516, 15P(X=n) = P(X=n−1)일 때 E(X)

풀이 패턴: 점화관계로 p → 분산으로 n → E=np
P(X=n) = pn,   P(X=n−1) = npn−1q
15pn = npn−1q  ⇒  15p = nq = n(1−p)  ⋯ (*)

V(X) = npq = nq · p에서 (*)를 대입:

nq · p = 15p · p = 15p2 = 1516  ⇒  p2 = 116  ⇒  p = 14

(*)에서: n · 34 = 15 × 14 = 154  ⇒  n = 5

E(X) = 5 × 14 = 54

정규분포 구간 확률 최대

문제: X ~ N(7, 22)일 때 P(a−1 ≤ X ≤ a+3)이 최대인 a

풀이 패턴: 구간 중점이 평균과 일치할 때 확률 최대

a + 1 = 7  ⇒  a = 6
포인트 길이가 고정된 구간의 확률을 최대화하려면, 구간의 중점을 평균에 맞추면 된다.
