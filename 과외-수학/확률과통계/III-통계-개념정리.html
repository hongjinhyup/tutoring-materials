III. 통계 — 개념 정리p. 1

중단원 1. 확률분포

1-1. 확률변수와 확률분포

확률변수란 우연 현상의 각 결과에 하나의 숫자를 대응시킨 것입니다.

  • 예: 동전 두 개를 던질 때 ‘앞면이 나온 횟수’를 X 라 하면 — 뒤뒤 → X=0, (앞뒤·뒤앞) → X=1, 앞앞 → X=2
  • X 가 어떤 값 x 를 가질 확률을 P(X=x) 로 씁니다.

확률분포는 확률변수가 가지는 값과 그 확률 사이의 대응 관계 전체이며, 보통 확률분포표나 그래프로 나타냅니다. 값이 셀 수 있을 때(0, 1, 2, …)를 이산확률변수라 하고, 각 값에 확률을 대응시킨 P(X=xi)=pi 를 확률질량함수라고 합니다.

모든 확률분포가 반드시 만족하는 두 성질
① 0 ≤ pi ≤ 1     ② p1 + p2 + ⋯ + pn = 1
이 두 성질은 상수 a 를 구하는 문제의 출발점이 되므로 꼭 기억하세요.

1-2. 이산확률변수의 평균(기댓값)

평균은 분포의 중심, 즉 “평균적으로 어떤 값이 나올까”를 알려줍니다. 각 값에 그 확률을 곱해서 모두 더합니다 — 단순 평균이 아니라 확률을 가중치로 준 평균입니다.

E(X) = x1p1 + x2p2 + ⋯ + xnpn = ∑i=1n xipi

기호는 E(X) 또는 m(mean)으로 씁니다.

1-3. 분산과 표준편차 (이 단원의 핵심)

평균이 같아도 값들이 평균 가까이 모일 수도, 멀리 흩어질 수도 있습니다. 이 흩어진 정도(산포)를 재는 것이 분산과 표준편차입니다.

분산의 정의 — 편차의 제곱의 평균
V(X) = E((X−m)2) = (x1−m)2p1 + ⋯ + (xn−m)2pn
편차 (X−m) 를 그냥 더하면 항상 0이 되므로, 제곱으로 부호를 없앤 뒤 평균을 냅니다.
분산 계산 공식 — 실전에서 거의 이 식을 사용
V(X) = E(X2) − {E(X)}2

외우는 말: “제곱의 평균 빼기 평균의 제곱”

E(X2) = x12p1 + x22p2 + ⋯ + xn2pn

표준편차는 분산의 양의 제곱근입니다.

σ(X) = V(X)

분산은 제곱을 했기에 단위가 원래의 제곱(cm → cm2)이 됩니다. 다시 제곱근을 씌워 원래 단위로 되돌린 것이 표준편차이며, 표준편차가 클수록 분포가 넓게 흩어져 있다고 해석합니다.

예제 — 교과서 106p [기본 2]

X=1, 2, 3, 4, 확률질량함수 P(X=x) = x10 일 때 평균·분산·표준편차를 구하라.

X1234합
P(X=x) 110 210 310 410 1
E(X) = 1·1 + 2·2 + 3·3 + 4·410 = 3010 = 3
E(X2) = 12·1 + 22·2 + 32·3 + 42·410 = 10010 = 10
V(X) = 10 − 32 = 1,    σ(X) = 1 = 1

1-4. 확률변수 aX + b 의 변환

X 를 a 배 하고 b 를 더한 새 변수 aX+b 의 평균과 분산은 다음과 같습니다.

E(aX+b) = aE(X) + b
V(aX+b) = a2V(X)     σ(aX+b) = |a| σ(X)
  • +b (평행이동)은 분포를 통째로 옆으로 밀 뿐, 흩어진 정도는 그대로 → 분산에 영향 없음
  • ×a (배율)은 흩어짐을 키우거나 줄임 → 분산은 a2, 표준편차는 |a| 만큼
자주 틀리는 점 분산에는 b 가 들어가지 않고, a 는 제곱으로 붙습니다. 표준편차는 절댓값 |a| 라는 점도 주의하세요.
III. 통계 — 개념 정리p. 4

1-5. 표준화 (변수 Z)

평균 m, 표준편차 σ 인 확률변수 X 를 다음처럼 바꾸면, 새 변수 Z 는 평균이 0, 표준편차가 1이 됩니다.

Z = X − mσ   ⟹   E(Z) = 0,   σ(Z) = 1

서로 다른 분포를 같은 잣대로 비교하는 도구이며, 뒤에서 정규분포 확률을 계산할 때 핵심이 됩니다.

1-6. 이항분포 B(n, p)

같은 시행을 독립적으로 n번 반복할 때, 어떤 사건이 일어나는 횟수 X 가 따르는 분포입니다. (한 번의 성공 확률 p, 실패 확률 q = 1−p)

P(X=x) = nCx px qn−x   (x = 0, 1, 2, …, n)
베르누이 시행 ① 결과가 두 가지(성공/실패)   ② 매번 성공 확률이 일정   ③ 각 시행이 서로 독립
이항분포의 평균·분산·표준편차 (표 없이 바로 공식)
E(X) = np,    V(X) = npq,    σ(X) = npq
예) X ~ B(50, 25) 이면 E(X) = 50 · 25 = 20,  V(X) = 50 · 25 · 35 = 12

큰수의 법칙: 시행 횟수 n 을 아주 크게 하면 상대도수 Xn 가 실제 확률 p 에 점점 가까워집니다. “여러 번 해 보면 이론적 확률에 수렴한다”를 수학적으로 표현한 것입니다.

1-7. 정규분포 N(m, σ²)

지금까지는 값이 띄엄띄엄 떨어진 이산확률변수였지만, 키·몸무게·시간처럼 연속적인 값을 가지는 변수를 연속확률변수라 합니다. 이때 확률은 곡선 아래의 넓이로 나타냅니다.

연속확률변수 중 가장 중요한 것이 정규분포입니다. 그래프는 평균 m 을 중심으로 좌우 대칭인 종 모양 곡선입니다.

정규분포 그래프의 성질
  • 직선 x = m 에 대칭, 가장 높은 점은 x=m
  • 평균 m 은 곡선의 위치, 표준편차 σ 는 곡선의 폭을 결정
  • σ 가 작으면 뾰족하고 좁게, 크면 완만하고 넓게 퍼짐

표준정규분포: 평균 0, 분산 1인 정규분포 N(0, 1) 이며 이 변수를 Z 로 씁니다. 확률은 표준정규분포표에서 P(0 ≤ Z ≤ z) 값을 읽어 구합니다.

정규분포의 표준화: 일반 정규분포 N(m, σ2) 의 확률도 표준화를 거치면 표를 써서 계산할 수 있습니다.

P(a ≤ X ≤ b) = P(a−mσ ≤ Z ≤ b−mσ)
자주 쓰는 구간 확률 (대칭성으로 기억)
P(|X−m| ≤ σ) ≈ 0.6826
P(|X−m| ≤ 2σ) ≈ 0.9544
P(|X−m| ≤ 3σ) ≈ 0.9974

이항분포의 정규분포 근사: 이항분포 B(n, p) 도 n 이 충분히 크면 정규분포로 근사할 수 있습니다.

X ~ B(n, p)  ⟹  X ≈ N(np, npq)

이항분포의 평균(np)과 분산(npq)을 그대로 정규분포의 m, σ2 자리에 넣는 것이 핵심입니다.

중단원 2. 통계적 추정

2-1. 모집단과 표본

  • 모집단: 조사하려는 대상 전체
  • 표본: 조사를 위해 모집단에서 뽑은 일부
  • 전수조사: 모집단 전체를 조사 (정확하지만 비용·시간이 큼)
  • 표본조사: 표본만 조사해 전체를 추측 (현실적으로 대부분 이 방법)

임의추출: 모집단의 모든 대상이 같은 확률로 뽑히도록 치우침 없이 뽑는 방법. 뽑은 것을 되돌려 넣으면 복원추출, 되돌리지 않으면 비복원추출입니다.

모집단의 값 vs 표본의 값 (기호 혼동 주의)
구분평균분산표준편차
모집단모평균 m모분산 σ2모표준편차 σ
표본표본평균 X표본분산 S2표본표준편차 S
주의 표본분산은 n 이 아니라 n−1 로 나눕니다.
S2 = 1n−1 { (X1−X)2 + ⋯ + (Xn−X)2 }

2-2. 표본평균의 분포

표본을 뽑을 때마다 표본평균 X 값은 달라집니다. 즉 표본평균 자체가 하나의 확률변수이고, 그 나름의 분포(평균·분산)를 가집니다.

모평균 m, 모표준편차 σ 인 모집단에서 크기 n 인 표본을 뽑을 때,

E(X) = m,    V(X) = σ2n,    σ(X) = σn
  • 표본평균의 평균은 모평균과 같다 → 표본평균은 모평균을 추측하기 좋은 값
  • 표본 크기 n 이 커질수록 흩어짐 σn 은 작아진다 → 표본이 클수록 더 정확

모집단이 정규분포면 표본평균도 정규분포를 따르고, 아니어도 n 이 충분히 크면 근사적으로 정규분포를 따릅니다.

X ~ N(m, σ2n)   ⟹   Z = X − mσn
III. 통계 — 개념 정리p. 8

2-3. 모평균의 추정 (신뢰구간)

표본 정보로 모평균 m 을 추측하는 것을 추정, 모평균이 들어 있을 것으로 기대되는 구간을 신뢰구간이라 합니다. 모표준편차 σ 를 알고 표본평균이 x 일 때,

신뢰도 95 % 신뢰구간
x − 1.96 σn ≤ m ≤ x + 1.96 σn
신뢰도 99 % 신뢰구간
x − 2.58 σn ≤ m ≤ x + 2.58 σn
꼭 알아 둘 점
  • 1.96, 2.58은 표준정규분포표에서 나오는 값(신뢰도 95 %, 99 %)이므로 외워 둡니다.
  • 신뢰구간의 길이 = 2 × (신뢰계수) × σn. 신뢰도를 높이면(95→99 %) 구간이 길어지고(덜 정밀), 표본 크기 n 을 키우면 구간이 짧아집니다(더 정밀).
  • “신뢰도 95 %”의 의미: 같은 방법으로 표본을 여러 번 뽑아 구간을 만들면, 그중 약 95 %가 모평균 m 을 포함한다는 뜻입니다.

공부 순서 제안

  1. 확률변수 → 확률분포표 만들기를 손으로 직접 그려 보기 (모든 계산의 출발점)
  2. 평균 → 분산(E(X2)−{E(X)}2) → 표준편차 순서대로 구하는 연습
  3. aX+b 변환 공식은 표준편차의 |a|, 분산의 a2 를 헷갈리지 않게 반복
  4. 이항분포는 공식 np, npq 로 바로 구하는 데 익숙해지기
  5. 정규분포는 표준화 → 표준정규분포표 읽기 흐름을 몸에 익히기
  6. 통계적 추정은 표본평균 분포(σn)와 신뢰계수(1.96, 2.58)만 정확히 외우면 대입 문제

자주 틀리는 부분 — 시험 직전 체크

아래 5가지만 안 틀려도 점수가 오릅니다
  1. 분산을 구할 때 {E(X)}2 대신 E(X2) 를 빼는 실수
  2. 분산 변환에서 +b 를 더해 버리는 실수 (V(aX+b)=a2V(X), b 는 무관)
  3. 표본분산은 n 이 아니라 n−1 로 나눈다
  4. 표본평균의 표준편차는 σ 가 아니라 σn
  5. 신뢰도를 높이면 구간이 넓어진다(정밀도는 떨어진다)
마무리 이 단원은 “표를 만들고 → 공식에 대입”하는 흐름이 80 %입니다. 공식을 외우는 것보다 각 공식이 분포의 무엇(중심·흩어짐·정확도)을 재는지 의미를 함께 떠올리며 풀면 실수가 크게 줄어듭니다.
