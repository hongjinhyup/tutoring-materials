문항별 필수 개념 안내

각 문항을 풀기 위해 반드시 알아야 하는 개념을 정리하였다. 개념을 먼저 확인한 뒤 풀이에 들어간다.

❶ 전수조사와 표본조사  → 기본 1 (p.120)

모집단의 모든 대상을 조사하는 것을 전수조사라 하고, 일부만 뽑아 조사하는 것을 표본조사라 한다.

파괴검사이거나 비용이 과도하면 표본조사가 적합하고, 전수 파악이 가능하면 전수조사가 적합하다.

❷ 표본평균의 분포  → 기본 2 · 표준 5 · 표준 6 (p.120~121)

모평균 m, 모분산 σ2인 정규모집단에서 크기 n인 표본을 추출하면 X ~ N(m, σ2n)이다.

E(X) = m,   V(X) = σ2n,   σ(X) = σn이다.

❸ 표본평균의 확률 (정규분포 표준화)  → 기본 3 · 표준 7 · 표준 8 (p.120~121)

X ~ N(m, σ2n)일 때 Z = X − mσ / n 로 표준화하여 확률을 구한다.

표본합 S = nX이므로 S의 구간을 n으로 나누어 X 구간으로 변환한 뒤 표준화한다.

❹ 모평균의 신뢰구간 추정  → 기본 4 · 표준 9 · 표준 10 · 표준 11 (p.121~122)

신뢰도 95%: X ± 1.96 × σn,   신뢰도 99%: X ± 2.58 × σn이다.

신뢰구간의 중심이 x이고, 오차한계(반폭)에서 n을 역산할 수 있다.

❺ 이산확률변수의 표본평균  → 발전 12 (p.122)

복원추출로 뽑은 값의 평균 X가 특정 값이 되려면 어떤 조합이 나와야 하는지를 따진다.

P(X = k)를 구한 뒤 확률 방정식을 세워 미지수를 결정한다.

❻ 표준화 대칭성과 신뢰구간 길이  → 발전 13 · 발전 14 (p.122)

P(Z < a) = P(Z ≥ −a)인 대칭성을 이용하여 X와 X의 확률을 연립한다.

신뢰구간 길이는 1n에 비례하므로, 길이를 1k배로 줄이려면 n을 k2배로 늘린다.

기본 (1~4)

기본 1

전수조사 vs 표본조사

문제: 다음 중 적합한 조사 방법을 보기에서 고르시오.
(1) A 고등학교 2학년 학생들의 수학여행 참여 여부 조사
(2) B 농장에서 재배한 수박의 당도 조사

풀이 패턴: 파괴검사·비용 과다 → 표본조사, 전수 가능 → 전수조사

(1) 학생 수가 유한하고 전수 가능 → 전수조사

(2) 당도는 수박을 잘라야 측정(파괴검사) → 표본조사

(1) 전수조사   (2) 표본조사

기본 2

표본평균의 E, V, σ

문제: 모평균이 20, 모분산이 2인 모집단에서 크기 9인 표본의 표본평균 X에 대해 (1) E(X)   (2) V(X)   (3) σ(X)

풀이 패턴: E = m, V = σ²/n, σ = σ/√n
주의 모분산이 σ2 = 2이다 (모표준편차 σ = 2).
E(X) = 20
V(X) = 29
σ(X) = 29 = 23

E = 20,   V = 29,   σ = 23

기본 3

표본평균의 확률

문제: 체육관 회원의 운동시간 ~ N(60, 162). 16명을 임의추출할 때 (1) P(56 ≤ X ≤ 66)   (2) P(X ≤ 48)

풀이 패턴: σ(X̄) = 16/√16 = 4 → 표준화

(1)

Z1 = 56 − 604 = −1,   Z2 = 66 − 604 = 1.5
P(56 ≤ X ≤ 66) = P(−1 ≤ Z ≤ 1.5) = P(0 ≤ Z ≤ 1) + P(0 ≤ Z ≤ 1.5)
= 0.3413 + 0.4332 = 0.7745

(2)

Z = 48 − 604 = −3
P(X ≤ 48) = P(Z ≤ −3) = 0.5 − P(0 ≤ Z ≤ 3) = 0.5 − 0.4987 = 0.0013

(1) 0.7745   (2) 0.0013

기본 4

모평균의 신뢰구간

문제: N(m, 302) 모집단에서 크기 n인 표본을 추출하여 표본평균이 324일 때
(1) n = 100, 신뢰도 95%의 신뢰구간   (2) n = 25, 신뢰도 99%의 신뢰구간

풀이 패턴: 95% → ±1.96σ/√n, 99% → ±2.58σ/√n

(1)

324 ± 1.96 × 30100 = 324 ± 1.96 × 3 = 324 ± 5.88

318.12 ≤ m ≤ 329.88

(2)

324 ± 2.58 × 3025 = 324 ± 2.58 × 6 = 324 ± 15.48

308.52 ≤ m ≤ 339.48

표준 5

E(X), V(X)로 σ 역산

문제: 평균 25, 표준편차 σ인 모집단에서 크기 n인 표본을 추출할 때 E(X) = n4, V(X) = 120이다. σ의 값을 구하시오.

풀이 패턴: E(X̄) = m으로 n 결정 → V(X̄) = σ²/n으로 σ 결정
E(X) = 25  ⇒  n4 = 25  ⇒  n = 100
V(X) = σ2100 = 120
σ2 = 10020 = 5  ⇒  σ = 5

문제: N(50, 82) 모집단에서 크기 16인 표본의 합을 X라 할 때 P(768 ≤ X ≤ 832)

표준 8  서술형

|X − m| ≤ 1 확률로 n 구하기

문제: N(m, 202) 모집단에서 크기 n인 표본을 추출할 때 |X − m| ≤ 1일 확률이 0.96이다. n의 값을 구하시오.
(단, P(0 ≤ Z ≤ 2) = 0.48)

풀이 패턴: P(|X̄−m| ≤ 1) = 0.96 → 표준화 → P(0 ≤ Z ≤ z) = 0.48 → z = 2
P(|X − m| ≤ 1) = P(|X − m20 / n| ≤ n20) = 0.96
2 P(0 ≤ Z ≤ n20) = 0.96  ⇒  P(0 ≤ Z ≤ n20) = 0.48
n20 = 2  ⇒  n = 40  ⇒  n = 1600

n = 1600

발전 (12~14)

발전 12

주머니 공 표본평균

문제: 1이 적힌 공 1개와 3이 적힌 공 n개가 들어 있는 주머니에서 복원추출로 2번 꺼내어 평균을 X라 하자. P(X = 2) = 38일 때 n의 값을 구하시오.

풀이 패턴: X̄ = 2 → (1,3) 또는 (3,1) → 확률 방정식
P(X = 2) = 2 × 1n + 1 × nn + 1 = 2n(n + 1)2
2n(n + 1)2 = 38
16n = 3(n + 1)2 = 3n2 + 6n + 3
3n2 − 10n + 3 = 0
(3n − 1)(n − 3) = 0  ⇒  n = 13 (부적합)  또는  n = 3

n = 3

발전 13  서술형

P(X < 110) = P(X ≥ a)

문제: X ~ N(100, 52)이고 크기 4인 표본의 표본평균을 X라 할 때 P(X < 110) = P(X ≥ a)를 만족시키는 a의 값을 구하시오.

풀이 패턴: 양변 표준화 → Z값 대칭성 이용

[좌변]

P(X < 110) = P(Z < 110 − 1005) = P(Z < 2)

[우변]

X ~ N(100, (52)2)  →  σ(X) = 52 = 2.5

P(X ≥ a) = P(Z ≥ a − 1002.5)

[연립]

P(Z < 2) = P(Z ≥ −2)이므로

a − 1002.5 = −2  ⇒  a − 100 = −5  ⇒  a = 95

a = 95

발전 14  추론

신뢰구간 길이 비교

문제: 정규분포를 따르는 모집단에서 크기 50인 표본으로 95% 신뢰구간 a ≤ m ≤ b를 얻었다. 같은 신뢰도로 크기 n인 표본을 사용했더니 신뢰구간이 c ≤ m ≤ d이고 d − c = 12(b − a)이다. n의 값을 구하시오.

풀이 패턴: 신뢰구간 길이 ∝ 1/√n → 길이 1/2배면 n을 4배
b − a = 2 × 1.96 × σ50
d − c = 2 × 1.96 × σn
d − c = 12(b − a)  ⇒  σn = 12 · σ50
n = 250  ⇒  n = 4 × 50 = 200

n = 200
