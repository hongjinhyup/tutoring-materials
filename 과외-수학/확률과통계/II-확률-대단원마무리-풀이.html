II. 확률 — 대단원 마무리 풀이p. 1

문항별 필수 개념 안내

각 문항을 풀기 위해 반드시 알아야 하는 개념을 정리하였다. 개념을 먼저 확인한 뒤 풀이에 들어간다.

❶ 수학적 확률과 배열  → 종합 1 · 종합 2 · 종합 3 (p.71)

순열·조합·부분집합으로 경우의 수를 세고 전체로 나눈다. 양 끝 배열, 부분집합 포함 조건, 정수해 부등식 등 다양한 유형이 출제된다.

❷ 배반사건과 덧셈정리·드모르간  → 종합 4 · 종합 6 (p.71)

배반이면 P(A ∪ B) = P(A) + P(B). 드모르간 법칙으로 P(Ac ∩ Bc) = 1 − P(A ∪ B)를 이용한다.

❸ 조건부확률과 분할표  → 종합 5 · 종합 7 (p.71)

표에서 "~일 때"가 새로운 분모가 된다. P(A ∩ Bc) = P(A) − P(A ∩ B)를 활용한다.

❹ 독립의 곱셈과 역산  → 종합 8 · 종합 11 (p.72)

독립이면 P(둘 다) = P(A)P(B). 역으로 P(B)를 구하는 문제가 자주 출제된다.

❺ 비복원 추출과 곱셈정리  → 종합 9 (p.72)

순차 비복원은 곱셈정리를 적용한다. ab = 값, a + b = 합 조건에서 이차방정식을 세운다.

❻ 베이즈 정리  → 종합 10 (p.72)

확률나무를 그린 뒤 사후확률을 구한다. 분자·분모의 경로를 정확히 파악하는 것이 핵심이다.

❼ 직병렬 회로와 독립  → 종합 12 (p.72)

직렬 = AND (곱), 병렬 = OR (여사건). 전류가 안 흐를 확률을 여사건으로 구하면 편리하다.

❽ 독립시행(이항분포)  → 종합 13 · 서술형 17 (p.72~73)

nCr pr qn−r. 복귀 조건은 mod로 판단한다.

❾ 판별식과 확률  → 서술형 14 (p.73)

D = a2 − 4b ≥ 0 → a 값별로 b의 범위를 세는 경우의 수 문제이다.

종합 1

양 끝 배열

문제: 4명을 일렬로 세울 때, 준영이와 하선이가 양 끝에 서는 확률을 구하여라.

풀이 패턴: 전체 배열 → 조건 배열 → 확률
전체: 4! = 24
양 끝(준영·하선): 2! × 나머지 2! = 2 × 2 = 4
P = 424 = 16

16

종합 2

부분집합에 5 미포함

문제: A = {1, 2, 3, 4, 5}의 부분집합을 임의로 택할 때, 원소 5를 포함하지 않을 확률을 구하여라.

풀이 패턴: 전체 부분집합 → 5 없는 부분집합
전체 부분집합: 25 = 32
5를 포함하지 않는 부분집합: {1, 2, 3, 4}의 부분집합 = 24 = 16
P = 1632 = 12

12

종합 3

정수해 조건과 확률

문제: x + y = 100을 만족시키는 양의 정수 순서쌍 (x, y) 중 하나를 택할 때, xy ≥ 2400일 확률을 구하여라.

풀이 패턴: 부등식 → 범위 세기
전체: x = 1, 2, …, 99 → 99가지

xy = x(100 − x) ≥ 2400

x2 − 100x + 2400 ≤ 0  ⇒  (x − 40)(x − 60) ≤ 0
40 ≤ x ≤ 60  →  21개
P = 2199 = 733

733

종합 4

배반 + 드모르간

문제: 사건 A, B가 배반이고 P(A) = 14, P(Ac ∩ Bc) = 18일 때 P(B)를 구하여라.

풀이 패턴: 드모르간 → P(A∪B) 구하기 → 배반 이용
P(Ac ∩ Bc) = 1 − P(A ∪ B)
18 = 1 − P(A ∪ B)  ⇒  P(A ∪ B) = 78

배반이므로 P(A ∪ B) = P(A) + P(B)

P(B) = 78 − 14 = 78 − 28 = 58

58

종합 6

배반·여사건 성질 (옳지 않은 것)

문제: A, B가 배반이고 C = Ac일 때, 옳지 않은 것은?

풀이 패턴: 배반 + 여사건 성질 하나씩 검증

① P(A ∩ B) = 0  → 배반이므로 참

② P(A ∪ C) = 1  → C = Ac이므로 A ∪ Ac = S, 참

③ P(B) ≤ P(C)  → B ⊆ Ac = C이므로 참

④ 0 < P(A ∩ B) < 1  → A ∩ B = ∅이므로 P = 0, 거짓

⑤ P(C | B) = 1  → B ⊆ C이므로 참

④

종합 7

P(A ∩ Bc) 구하기

문제: P(A) = 13, P(Bc) = 34, P(B | A) = 13일 때 P(A ∩ Bc)를 구하여라.

풀이 패턴: 곱셈정리 → P(A∩B) → 차집합
P(A ∩ B) = P(A) · P(B | A) = 13 × 13 = 19
P(A ∩ Bc) = P(A) − P(A ∩ B) = 13 − 19 = 39 − 19 = 29

29

함정 P(Bc) = 34는 이 풀이에서 사용하지 않는 미끼 조건이다. 주어진 조건을 모두 써야 한다는 선입견에 빠지지 말 것.
종합 8

독립 두 경기

문제: 축구 승률 23, 농구 승률 r이고 두 경기가 독립일 때, 둘 다 이길 확률이 13이면 r을 구하여라.

풀이 패턴: 독립 → P(둘다) = P(A)·P(B)
23 × r = 13  ⇒  r = 13 ÷ 23 = 12

12

종합 9

비복원 순차 추출

문제: 빨간 공과 파란 공이 합쳐 7개인 주머니에서 갑이 빨간 공 1개, 을이 파란 공 1개를 비복원으로 뽑을 확률이 27이고, 파란 공이 빨간 공보다 많을 때 파란 공의 수를 구하여라.

풀이 패턴: 곱셈정리 → ab = 값, a+b = 합 → 이차방정식

빨간 a개, 파란 b개라 하면 a + b = 7

a7 × b6 = 27  ⇒  ab42 = 27  ⇒  ab = 12

a + b = 7,   ab = 12  →  a = 3, b = 4  (파랑 > 빨강)

4개

종합 11

독립 + 배반 혼합

문제: A, B는 독립, B, C는 배반이고 P(A) = 0.4, P(A ∩ B) = 0.3, P(B ∪ C) = 0.9일 때 P(C)를 구하여라.

풀이 패턴: 독립 → P(B) 역산 → 배반 → P(C)
P(A ∩ B) = P(A) · P(B)  ⇒  0.3 = 0.4 × P(B)
P(B) = 0.30.4 = 0.75

B, C 배반이므로

P(B ∪ C) = P(B) + P(C)  ⇒  P(C) = 0.9 − 0.75 = 0.15

0.15

종합 12

직병렬 회로

문제: 윗가지에 스위치 A(작동 확률 0.9), 아랫가지에 B(0.8)와 C(0.7)가 직렬 연결되어 있다. 두 가지는 병렬로 연결되어 있을 때, 전류가 흐를 확률을 구하여라.

풀이 패턴: 여사건 — 전류 안 흐를 확률
아랫가지 = P(B) × P(C) = 0.8 × 0.7 = 0.56
전류 안 흐름 = (1 − 0.9) × (1 − 0.56) = 0.1 × 0.44 = 0.044
P(전류 흐름) = 1 − 0.044 = 0.956
포인트 병렬 = "적어도 하나가 흐르면 OK"이므로 여사건(둘 다 안 흐름)이 더 편리하다.

0.956

종합 13

정사각형 점 이동 (독립시행)

문제: 정사각형 ABCD의 꼭짓점 A에서 출발. 주사위를 던져 1 또는 2 → 반시계 1칸, 3~6 → 시계 1칸 이동한다. 4번 던진 후 A에 있을 확률을 구하여라.

풀이 패턴: 독립시행 + mod 4 복귀 조건

p(반시계) = 13,   q(시계) = 23

반시계 k번이면 시계 (4 − k)번. 변위 = −k + (4 − k) = 4 − 2k

A 복귀 조건: 4 − 2k ≡ 0 (mod 4) → k = 0, 2, 4

k = 0: 4C0 (13)0 (23)4 = 1681
k = 2: 4C2 (13)2 (23)2 = 6 × 19 × 49 = 2481
k = 4: 4C4 (13)4 = 181
P = 16 + 24 + 181 = 4181

4181

서술형 16

독립 판정

문제: P(A) = 12, P(B) = 13, P(A | B) + P(B | A) = 56일 때, A와 B가 독립인지 판정하여라.

풀이 패턴: P(A∩B) = x로 놓고 조건부확률 역산

P(A ∩ B) = x로 놓으면

P(A | B) = x13 = 3x,   P(B | A) = x12 = 2x
3x + 2x = 5x = 56  ⇒  x = 16

독립 검증:

P(A) · P(B) = 12 × 13 = 16 = P(A ∩ B)

P(A)P(B) = P(A ∩ B)이므로

A와 B는 독립이다

좌석 부족 확률 (독립시행)

취소 횟수 X ~ B(5, 14)

좌석 부족: 방문자 ≥ 4명 → 취소 ≤ 1명

P(X = 0) = (34)5 = 2431024
P(X = 1) = 5C1 × 14 × (34)4 = 5 × 14 × 81256 = 4051024
P(X ≤ 1) = 243 + 4051024 = 6481024 = 81128
